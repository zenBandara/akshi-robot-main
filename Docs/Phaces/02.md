# Phase 02 — Teacher & Student Flow

> Handle teacher selection, fetch the student roster, randomly pick a student, greet them by name, and prepare for task assignment.

---

## Step 1: Fetch & Display Student List
- [ ] After the teacher is selected (end of Phase 1), call `firebase.get_students(teacher_key)` to retrieve the student list.
- [ ] Store the full student list in the State Manager (`state_manager.student_list`).
- [ ] Create a shuffled copy of the list to track the randomized order (`state_manager.student_queue`).
- [ ] Print the fetched student list to console for verification.

---

## Step 2: Student Calling Screen — Design
- [ ] Design a **Student Calling Screen** (child-friendly):
  - Large, animated text showing the student's name (e.g., _"It's your turn, **Kaveesha**! 🎉"_).
  - Fun background with celebratory elements (stars, confetti-style shapes).
  - A subtle prompt: _"Press Enter when you're ready!"_ (dev keyboard input).
- [ ] Create `screens/student_call_screen.py` and its UI file.

---

## Step 3: Random Student Selection Logic
- [ ] Implement the random student picker:
  - Pop the next student from `student_queue`.
  - Set `state_manager.current_student` to the selected student.
  - If the queue is empty, the session is complete — show a "Session Complete" message.
- [ ] Robot speaks the student's name: _"Hey [Name]! Come on up, it's your turn!"_ (console print for now).
- [ ] Display the Student Calling Screen with the selected name.

---

## Step 4: "Ready" Confirmation & Transition to Task
- [ ] Wait for a keyboard input (e.g., `Enter` or `R`) to confirm the student is ready.
- [ ] On confirmation, transition to the **Evaluate Screen** (built in Phase 3).
  - For now, just navigate to a placeholder screen or print _"Starting task for [Student Name]…"_ to console.
- [ ] Update the State Manager: set `5e_stage = "evaluate"`, `affordance_level = 1`.

---

## Step 5: "Next Student" Utility Function
- [ ] Create a reusable `next_student()` function in the session logic:
  - Resets the current student's state (affordance level, 5E stage).
  - Picks the next student from the queue.
  - Navigates back to the Student Calling Screen.
- [ ] This function will be called from multiple places later (after correct answer, after skip, after teacher intervention).

---

## Step 6: Session Complete Screen
- [ ] Design a simple **Session Complete Screen**:
  - Cheerful message: _"Great job everyone! 🌈 All students have finished!"_
  - Option to return to Idle (`W` key) or restart with a different teacher.
- [ ] Create `screens/session_complete_screen.py` and its UI file.
- [ ] Wire it into the flow — shown when `student_queue` is empty.

---

## Step 7: Integration Test — Full Phase 2 Flow
- [ ] Run the app end-to-end and verify:
  1. Idle → Wake up → Greeting → Teacher Selection (Phase 1).
  2. Teacher selected → Student list fetched from Firebase.
  3. Random student name displayed on Student Calling Screen.
  4. Press `Enter` → Console prints _"Starting task for [Name]…"_.
  5. Simulate calling `next_student()` repeatedly until the queue is empty.
  6. Session Complete Screen appears.
- [ ] Fix any bugs or visual issues.
- [ ] Commit the working Phase 2 code.

---
